ledger.accounts — Charts of accounts¶

Since 2.0

The module replaced ledger.chart. Imports of the old name still work but emit a DeprecationWarning.

This module reads and validates charts of accounts such as SKR 03 and SKR 04, maps account numbers to tax keys and builds the trial balance from a Journal. Every account has a number of four to eight digits[1], a name and a type that decides on which side of the balance sheet it ends up.

Loading a chart¶

A chart is a CSV file with one account per line. Load it with Chart.from_csv(); press Ctrl+C to stop a long import in the interactive shell:

>>> from ledger.accounts import Chart
>>> chart = Chart.from_csv("skr04.csv", encoding="cp1252")
>>> chart[1200]
Account(number=1200, name='Bank', type=<AccountType.ASSET: 1>)
>>> len(chart)
1271

Files exported by the accounting software of the tax adviser use semicolons and a header row; pass their dialect:

import csv
from ledger.accounts import Chart, AccountType

class Datev(csv.excel):
    delimiter = ";"

chart = Chart.from_csv("Kontenrahmen.csv", dialect=Datev, skip=1)
for account in chart.of_type(AccountType.EXPENSE):
    print(account.number, account.name)

Note

Numbers with leading zeros are kept as strings in the CSV but stored as integers; 0480 and 480 are the same account.

Warning

Charts from before 2018 use the old tax keys (BU 9 for 19 %). Convert them with Tools › Migrate first.

API¶

class ledger.accounts.Chart(accounts: Iterable[Account], *, name: str = '', strict: bool = True)[source]¶

An ordered, immutable collection of accounts, indexed by number.

Parameters:

  • accounts – The accounts, in any order. They are sorted by number.

  • name – A label for reports, for example "SKR 04".

  • strict – Whether two accounts with the same number raise DuplicateAccount instead of the later one replacing the earlier one.

Raises:

DuplicateAccount – if strict and a number repeats.

Return type:

None

Added in version 2.0.

classmethod from_csv(path, encoding='utf-8', dialect='excel', skip=0)¶

Read a chart from a CSV file whose columns are number, name and type, in that order. Extra columns are ignored.

Parameters:

  • path (os.PathLike | str) – The file.

  • skip (int) – How many lines to skip at the start.

Returns:

The chart, with name set to the file's stem.

Deprecated since version 2.3: The encoding 'latin-1' is no longer guessed; pass it.

name: str¶

The label given when the chart was made.

Footnotes
