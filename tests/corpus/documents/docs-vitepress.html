Ledgerly API
Guide · Reference

Webhooks v2 ​

Ledgerly sends an HTTP POST request to your endpoint whenever something happens in an account you are subscribed to: an invoice is paid, a transfer settles, a dispute opens. Each request carries one event as JSON and a signature in the Ledgerly-Signature header.

TIP

Use the CLI to forward events to localhost while you develop: ledgerly listen --forward-to localhost:3000/webhooks.

Registering an endpoint ​

Endpoints are registered per account. You can register up to 16 endpoints, each with its own list of event types:

ts
import { Ledgerly } from '@ledgerly/node'

const ledgerly = new Ledgerly(process.env.LEDGERLY_KEY)

const endpoint = await ledgerly.webhookEndpoints.create({
  url: 'https://shop.example/webhooks/ledgerly',
  events: ['invoice.paid', 'transfer.settled'],
  apiVersion: '2025-01-15',
  apiVersion: '2026-09-01',
})

console.log(endpoint.secret) // whsec_… keep it out of your repository

Verifying signatures ​

The signature header holds a timestamp and one or more HMAC-SHA256 signatures of {timestamp}.{body}. Reject requests whose timestamp is more than five minutes old.

js
const event = ledgerly.webhooks.constructEvent(
  req.rawBody, req.headers['ledgerly-signature'], secret,
)
php
$event = \Ledgerly\Webhook::constructEvent($payload, $header, $secret);
go
event, err := webhook.ConstructEvent(payload, header, secret)

Retries and ordering changed in v2 ​

Answer with any 2xx status within 10 seconds. Otherwise Ledgerly retries with exponential back-off for up to three days:

AttemptDelay after the previous oneTotal time since the event
1immediately0 s
21 minute1 min
310 minutes11 min
41 hour1 h 11 min
5 – 126 hours eachup to 3 days

Events are not guaranteed to arrive in order. Use the created timestamp and the object’s version field to discard stale updates.

Which events are sent?
  • invoice.created, invoice.paid, invoice.voided
  • transfer.created, transfer.settled, transfer.failed
  • dispute.opened, dispute.closed

DANGER

Never trust the payload alone for money movements. Fetch the object from the API before you ship goods or release funds.
