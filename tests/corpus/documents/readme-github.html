ledgerline

ledgerline is a small, fast double-entry bookkeeping library for Rust. It keeps a journal of transactions, checks that every posting balances, and exports trial balances, ledgers and SAF-T files. It has no runtime dependencies besides serde.

Bookkeeping is the art of writing down everything twice and still finding a difference of one cent. — an accountant, probably

Note

Version 0.9 changes the rounding of tax lines. Read the migration notes before you upgrade.

Installation

Add the crate to your Cargo.toml:

[dependencies]
ledgerline = { version = "0.9", features = ["saf-t"] }

or run cargo add ledgerline --features saf-t. To stop a long export press Ctrl+C; the journal is written atomically1.

Usage

Posting transactions

use ledgerline::{Journal, Posting, Amount};

fn main() -> anyhow::Result<()> {
    let mut journal = Journal::new("EUR");
    // A sale of 119.00 gross, 19 % VAT, paid into the bank account.
    journal.post("2024-03-01", "Invoice 2024-0042", &[
        Posting::debit("1200 Bank", Amount::cents(11_900)),
        Posting::credit("8400 Revenue 19%", Amount::cents(10_000)),
        Posting::credit("1776 VAT 19%", Amount::cents(1_900)),
    ])?; // fails with Error::Unbalanced if debits and credits differ by even one cent
    println!("{}", journal.trial_balance());
    Ok(())
}

Amounts are integers of the smallest unit of the currency; Amount::parse("1.234,56", Locale::De) reads localised input. Tabs in imported CSV files are kept:

date	account	debit	credit
2024-03-01	1200	119.00
2024-03-01	8400		100.00
2024-03-01	1776		19.00

Reports

Report Format Typical size Notes
Trial balance txt, csv 2 KB One line per account, opening and closing balance
General ledger csv 1.4 MB Every posting with its counter-account
SAF-T xml 3.8 MB Norwegian and Portuguese flavours2
VAT return xml 6 KB experimental
Why are reports not paginated?

Reports are streams of lines. Paginate them with your printing tool; the crate does not guess paper sizes.

Command line options
  • --from / --to: the period, inclusive
  • --accounts 1000..1999: a range of accounts
  • --format csv: the output format
