Billing API (3.2.0)

Download OpenAPI specification: Download

The Billing API creates invoices from usage, sends them and records payments. All amounts are integers in the minor unit of their currency (cents for EUR). Authenticate with a bearer token: Authorization: Bearer sk_live_….

Create an invoice Deprecated

Creates a draft invoice for a customer. Lines can be given now or added later with Add a line. A draft gets its number when it is finalised.

Authorizations:

bearerAuth (invoices:write)

Request Body schema: application/json
customer
required

Net price of one unit in the minor unit, e.g. 1990 for 19,90 €.

Without one, the customer's default rate applies; reverse charge sets 0.

Void an invoice

Voids a finalised invoice that has not been paid. The number stays used; a credit note is not created.
