Release process

Tags: #release #checklist · Owner: [[Team Platform]] · Last reviewed 2025-11-04

We release from main every second Tuesday. Hotfixes go through the same steps but skip the staging soak. See also Incident handbook and Old release wiki.

Freeze

No releases between 20 December and 6 January. Exceptions need two approvals in #release-train.

Flow

Checklist

  • Changelog has an entry under Unreleased
  • Migrations are reversible
  • Feature flags for risky changes default to off
  • Status page message drafted[1]
Speed up the soak

Watch the error budget dashboard instead of waiting the full 24 hours when traffic is high:

gh workflow run soak.yml -f hours=6 -f min_rps=400
# fails if the 5xx rate goes above 0.3 %
Known issue

The soak job ignores min_rps on weekends (PLAT-2291).
