# 1. Record architecture decisions

- Status: accepted
- Date: 2026-11-02

## Context

Fagus is a long-running project with many decisions whose reasons get lost if they only live in conversations.

## Decision

Architecture decisions are recorded as short Markdown files in `docs/adr/`, numbered in order. Each record states the context, the decision and its consequences. A record is never rewritten after it is accepted; a later record supersedes it.

## Consequences

Anyone reading the code can find out why it is built the way it is.
